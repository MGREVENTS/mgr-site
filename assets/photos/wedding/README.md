# Photos mariage — à déposer ici

Dépose les fichiers ci-dessous dans ce dossier (`assets/photos/wedding/`),
avec les **mêmes noms exacts**. Format **.webp** de préférence (ou .jpg, mais
préviens-moi pour ajuster le `.webp` → `.jpg` dans `config.js`).
Format web conseillé : largeur ~1600 px, poids < 400 Ko, qualité ~80.
(Si tu fournis les originaux, je peux les redimensionner/convertir.)
